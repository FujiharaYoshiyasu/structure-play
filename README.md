# 765Radical 開発用ブランチ

`structure-play` の `765-radical-dev` は、765Radicalの開発コードを保管する専用ブランチです。ソースコードの公開はユーザー承認済みですが、ホームページへの掲載・配信は承認されていません。

## ホームページと分離する

- `main` へマージしない。
- ホームページのリンク・メニュー・既存の `apps/765/` を変更しない。
- GitHub Pagesの配信元にこのブランチを指定しない。自動デプロイを追加しない。
- ホームページへの掲載を行う場合は、ユーザーの別途明示指示を受けてから実施する。

Codex向けの共通ルールは [AGENTS.md](AGENTS.md) を参照してください。

## 利用方法

このブランチをclone/checkoutし、`765Radical/index.html` をローカルのブラウザで開きます。公開サイトの765classicとは独立した開発版です。
