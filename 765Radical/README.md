# 765Radical — 特殊能力・AI研究用の開発版

> **ステータス:** `765-radical-dev` ブランチにのみ格納。公開ホームページの `main` および `apps/765/`（Classic）は変更しません。

## 現在の遊び方

1. `index.html` をブラウザで開くと、8×8のキャラクター編成が表示されます。
2. プレイヤーA／Bそれぞれ、数字0〜7に能力0〜1種類を設定（各チーム合計コスト3以下）。
3. 編成完了後、既存の対戦画面でCPU対戦／2人対戦／CPU同士対戦を実行します。
4. 途中で再編成した場合は、それまでの対局履歴が初期化されます。

| 能力 | コスト | 効果 |
|---|---:|---|
| E1 / D1 | 1 | 自分の既存コマ1枚を+1 ／ 相手の既存コマ1枚を−1 |
| E2 / D2 | 2 | 自分の既存コマ1枚を+2 ／ 相手の既存コマ1枚を−2 |
| E3 / D3 | 3 | 自分の既存コマ1枚を+3 ／ 相手の既存コマ1枚を−3 |
| SWITCH | 2 | 今回置いたコマと自分の既存コマ1枚の場所を交換 |
| DUBBLESTRIKE | 3 | このラウンドの自分の出力値上位2つを合計して得点 |

初期チームはA・Bとも数字4がE1、数字6がD1（合計コスト2）。詳細は [CHARACTER_ROSTER_RULES.md](./CHARACTER_ROSTER_RULES.md) を参照。

## AIの状況

CPU10段階は8能力を選択・発動できるように対応済みですが、**難易度の定量再調整は未実施**です。
ヒント・復習は従来のUIを維持。残り3マス以下を厳密探索、その他を簡易評価しています。1回戦の得点差を中心に評価し、2回戦全体の最善を保証しません。
