## 開く

`765Radical/index.html` をダウンロードしてブラウザで開きます。オフラインでもプレイできます。GitHubブランチにコードを保管するだけではWebサイトとして一般公開されません。

## 新機能

- **次の一手ヒント:** 現在の手番に対して上位候補を表示し、最上位候補の数字を選択してマスを強調
- **局面推定:** 序盤・中盤では簡易評価関数を使用。最善手の保証なし
- **終盤厳密探索:** 残り5マス以下では、赤−青の最終得点差をキャッシュ付きαβ探索。左上／右下対角線の反転を同型局面として扱う
- **指し手履歴:** 2回戦32手の各数字・配置・色を記録
- **対局復習:** 履歴から盤面を再現し、実際の手と推奨手の評価差を表示。厳密評価と推定評価を明示
- **JSONエクスポート:** 手順・得点・CPU設定をローカル保存

## 検証

Node.jsによる構文検査を通過。残り1〜5マスの44局面で、**全候補手の厳密得点差**が別実装の研究用ソルバーと一致。ブラウザの実画面については実行環境の制約により、今回の自動GUI動作試験を完了できていません。

## 現在の限界

- Ver.3のCPU強度10段階はそのまま。ヒント用AIは現行CPUには接続していません。
- 残り6マス以上のヒントは1手先の簡易評価のみで、必勝や最善を保証しません。
- 2回戦合計の最適化は未実装。厳密値はその回の赤・青の得点差です。
- MCTS・自己対戦学習は研究段階で、ブラウザCPUには未搭載。
- GitHub PagesでRadicalを公開しないこと。PrivateリポジトリでもPagesの公開設定によって公開サイトが発生することがあります。
