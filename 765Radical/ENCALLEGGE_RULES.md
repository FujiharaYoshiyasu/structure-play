# 765Radical — 選択式能力 Encallege / Discourage (試作ルール v0.2)

## 基本ルール
各プレイヤーは数字0〜7を各1枚、計8枚使う。能力があるかどうかは基礎数字に紐づく。赤・青の設定は共通で、色交代後も同じ数字が能力を持つ。

**初期値：各色2枚**
- **数字4：Encallege-1** — 場に出した瞬間、すでに盤上にある**自分の他のコマを1枚選んで**現在値を **+1** する。
- **数字6：Discourage-1** — 場に出した瞬間、すでに盤上にある**相手のコマを1枚選んで**現在値を **-1** する。

**対象のルール：**
- 効果は場に出した際に1回だけ発動し、効果の対象は**ちょうど1枚**。全体強化・全体弱体化はしない。
- 能力コマ自体にはその能力を適用しない。将来、別の能力の対象に選ぶことはできる。
- 数字の現在値の下限は0。0に -1 を当てても0のまま。
- 能力対象が盤上にない場合は**不発**。数字コマは通常どおり盤上に残る。
- 効果は永続で複数効果が重なる。以降に置かれるコマへ効果は遡及しない。
- 数字選択の使用済み判定は基礎数字0〜7で行い、積は強化・弱体化後の**現在値**で計算。
- 2回戦の開始時はコマの現在値を含めすべて初期化。

## 操作方法
1. 能力付きコマを選んで通常どおり空きマスに置く。
2. 対象候補があると、**緑の枠**で対象が強調される。いずれか1枚を押して確定。
3. 対象がない場合は自動で不発となり、次の手番へ。
4. CPUはコマの位置と能力対象を一つの行動として選択する。

初期の 4=E+1、6=D-1 は画面の「特殊能力／ルール設定」から変更可能。各数字に「なし、E+1〜E+7、D-1〜D-7」を設定できる。枚数も0〜8枚へ変更可能。変更すると対局リセット。

## 解析機能
- CPU10段階は対象選択を含む行動から選択する（難易度はまだ再較正が必要）。
- ヒントと履歴、対局復習、JSON保存は対象位置も記録する。
- **厳密探索は残り3マス以下**に変更。4マス以上は推定値なので必勝・最善を保証しない。
- 2回戦の最終総合最適化は未対応（各ラウンドの得点差で評価）。
